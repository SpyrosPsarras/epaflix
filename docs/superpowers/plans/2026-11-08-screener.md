# Daily stock screener implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Members of `Screener users` schedule their own Finviz screens in Windmill and get a daily email with entry, stop and target per match.

**Architecture:** Argo app `windmill` in `2-k3s/34.windmill/` renders the official Windmill Helm chart through Kustomize, with the database in the shared CNPG cluster. Traefik forward auth and Windmill's own Authentik login guard it. One shared Python script in workspace `screener` does the screening. Two PRs. Each live step waits for the owner.

**Tech stack:** Kustomize `helmCharts`, Windmill chart 4.0.313 (app 1.864.1), KSOPS/SOPS, Argo CD, Traefik, Authentik blueprints, CNPG `Database`/`DatabaseRole`, Prometheus Operator, promtool, Python 3, `finviz`, `wmill`, pytest.

**Spec:** `docs/superpowers/specs/2026-11-08-screener-design.md`.

## Global constraints

- Chart `windmill` from `https://windmill-labs.github.io/windmill-helm-charts`, version `4.0.313`. Image `ghcr.io/windmill-labs/windmill` `1.864.1`, pinned by digest. Re-check the digest with the registry before pinning.
- Hostname `windmill.epaflix.com` on Traefik `websecure`. Public DNS resolves through the Cloudflare wildcard and tunnel. The LAN needs Pi-hole lines pointing at `192.168.10.101`.
- Authentik group `Screener users`. Both Authentik applications bind it and `authentik Admins`.
- Secrets: generate values inside the command that writes them, using `vault run` with the cluster SOPS age key, then `sops set` or `sops -e`. Never print a value. List every `.enc.yaml` in `ksops-generator.yaml`. Edit the Authentik blueprint as the Secrets bullet of `docs/superpowers/plans/2026-11-04-music-stack.md` says.
- Live changes (merges, Argo syncs, Pi-hole, Authentik users, Windmill admin steps, `wmill` pushes) happen only after the owner confirms. Use the dry-run, then real Argo `operation` patch from the homelab SSH guide.
- Synthetic data only in tests. No real email addresses in Git.

## Review focus

1. An internet client outside `Screener users` opens `https://windmill.epaflix.com/` or `/api/version`. Expected: Authentik login or denial, never a Windmill response. Pinned in Task 2 Step 6.
2. A Windmill job runs `cat /proc/1/environ`, lists `/run/secrets` and connects to `postgres-cluster-rw.postgres-system.svc:5432`. Expected: no database URL in the output. Pinned in Task 2 Step 6.
3. A Windmill job opens `http://192.168.10.1`, `http://authentik-server.app-authentik.svc` and `https://finviz.com`. Expected: the first two time out, Finviz answers. Pinned in Task 2 Step 6.
4. A rule like `__import__('os').system('id')`, `[Price].__class__` or `[NoSuchColumn] * 2`. Expected: the run fails before scraping with a message naming the bad rule. Pinned in Task 3 Step 1.
5. A Finviz cell is `-` or `12.5%`, or a value has a thousands separator. Expected: `-` skips the row with a reason in the email, `12.5%` becomes `12.5`, `1,234.5` becomes `1234.5`. Pinned in Task 3 Step 1.
