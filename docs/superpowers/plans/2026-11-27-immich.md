# Immich Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Immich at `https://immich.epaflix.com` with Authentik OpenID login for "Servarr users", photos on `pithari/immich`, database in `postgres-cluster`, machine learning on the shared GPU, nightly encrypted copy to Google Drive.

**Architecture:** Official chart `oci://ghcr.io/immich-app/immich-charts/immich` 0.13.4 through kustomize `helmCharts` in `2-k3s/39.immich`, Argo CD app `immich`. Library on a static NFS PV from TrueNAS. Config file from a SOPS Secret through `immich.existingConfiguration`.

**Tech Stack:** Helm chart (bjw-s app-template), CNPG `Database`/`DatabaseRole`, Traefik IngressRoute, Authentik blueprint, TrueNAS API (`midclt`), Pi-hole dnsmasq.

**Spec:** `docs/superpowers/specs/2026-11-27-immich-design.md`

## Global Constraints

- Hostname `immich.epaflix.com`, Traefik `websecure` on `192.168.10.101`, no forward auth.
- Dataset `pithari/immich`: AES-256-GCM, generated key stored on TrueNAS, no passphrase. TrueNAS user and group `immich` 1001:1001, no login. NFS share for `192.168.10.61`-`65`, mapall `immich`.
- Database `immich`, role `immich` (login, not superuser), extensions `vchord`, `vector`, `cube`, `earthdistance`, on `postgres-cluster-rw.postgres-system.svc:5432`.
- Config: OAuth (issuer `https://auth.epaflix.com/application/o/immich/`, autoRegister, autoLaunch, roleClaim `immich_role`, defaultStorageQuota 0), `passwordLogin.enabled: false`, `server.externalDomain`, `storageTemplate.enabled: false`, `backup.database.enabled: false`.
- Machine learning: `-cuda` image, `runtimeClassName: nvidia`, nodeSelector `gpu: nvidia`, toleration `nvidia.com/gpu`, `nvidia.com/gpu: 1`.
- Cloud sync task: `/mnt/pithari/immich` to Google Drive `/epaflix-offsite/immich`, COPY, encrypted, daily 03:00, only `upload/` and `profile/`.
- Secrets are generated inside the command that writes them, never printed.

## Review Focus

- The NFS share refuses writes from the pods (mapall user or dataset permissions). Task 1 writes a file from a throwaway pod on a worker.
- Immich refuses to start because an extension is missing or not owned. Task 3 checks the server log for completed migrations.
- The OpenID redirect sends the wrong client id or callback. Task 4 checks `/api/oauth/authorize` returns an Authentik URL with the right `redirect_uri`.
- Uploads are capped by Traefik. Task 5 sends a 150 MB request to `/api/server/ping` through `192.168.10.101` and checks it is not refused with 413.
- The machine learning pod cannot get the GPU. Task 3 checks it schedules on `k3s-worker-64` and logs CUDA as provider.
