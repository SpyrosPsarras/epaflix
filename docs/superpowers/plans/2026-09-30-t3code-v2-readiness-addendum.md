## Monitoring renewal finding

The ordinary read-scoped session expires after about 30 days and cannot renew itself. The consumed bootstrap token and ordinary session both fail token exchange; read scopes cannot create new pairing tokens. Token-free socket counting cannot distinguish active clients from idle HTTP connections. Spyros chose scoped monitoring after reviewing that limitation and authorized isolated validation of local renewal. The successful probe minted a new read session through a one-minute administrative session, atomically replaced a private credential file and revoked the admin session. Production scheduling and failure-path implementation remain unapproved. Administrative access must remain separate from the steady read-only gate.
