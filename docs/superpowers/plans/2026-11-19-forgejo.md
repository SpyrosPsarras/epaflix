# Forgejo (PR 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run Forgejo at `git.epaflix.com`, admin-only behind Authentik, with its metadata in the existing CloudNativePG cluster and its repos on a `truenas-iscsi` volume.

**Architecture:** A new Argo app `2-k3s/38.forgejo` holds one Deployment, Service, PVC, IngressRoutes, network policy and SOPS Secrets. Its role and database live in `postgres-system`, following `2-k3s/36.home-assistant/database.yaml`. Authentik guards the site through the shared forward-auth middleware. Pi-hole gets the DNS name.

**Tech Stack:** Kubernetes manifests with kustomize and ksops, Argo CD, CloudNativePG `DatabaseRole`/`Database`, Traefik IngressRoute, Authentik blueprint, SOPS with age.

**Spec:** `docs/superpowers/specs/2026-11-19-rackpeek-homelab-index-design.md`, section "Forgejo (PR 1)".

## Global Constraints

- Image `codeberg.org/forgejo/forgejo`, tag `17.0.2-rootless@sha256:39362ab93a94c0c9b8b330d2a877ddbb3f02fa8c0cba1b8d686d437b39f36a04`, set through the `images:` block of `2-k3s/38.forgejo/kustomization.yaml` (Renovate's kustomize manager reads it).
- Namespace `forgejo`. App label `app: forgejo`. HTTP port 3000.
- Hostname `git.epaflix.com`. Traefik LB address in Pi-hole: the same address the `speedtest` line uses.
- Secret values never appear in chat, logs or plaintext files. Generate them inside the `vault run --name sops-age-k3s-cluster --password-env VAULT_SOPS_AGE_KEY -- sh -c 'SOPS_AGE_KEY="$VAULT_SOPS_AGE_KEY" …'` command that encrypts them. `.sops.yaml` already encrypts `data|stringData` in any `*.enc.yaml`.
- Decrypted files go only into a `mktemp -d -p .` directory with mode 700, deleted at the end of the task.
- No live `kubectl apply`, Argo sync, Pi-hole copy or Authentik change. This PR only changes Git.
- Never read or touch namespaces `t3code-work`, `mcp-hub-work`.
- No code comments. Commit titles are conventional, no co-author.

## Review Focus

1. Pod restart: Forgejo must start again with the same install lock and keys. Every `[security]` value comes from env, so a fresh `app.ini` is fine. Test: the Deployment env contains `FORGEJO__security__INSTALL_LOCK=true`, `SECRET_KEY` and `INTERNAL_TOKEN` from the Secret.
2. A second pod during rollout cannot attach the RWO iSCSI volume. Test: `strategy.type: Recreate`.
3. Read-only root and rootless UID: `/etc/gitea` must be writable (emptyDir), data on the PVC at `/var/lib/gitea`, `fsGroup: 1000`.
4. Argo drift from CNPG status fields. Test: the Application has the same `ignoreDifferences` as `app-home-assistant.yaml`.
5. Anonymous access. Test: the `https` IngressRoute carries `authentik-forwardauth`, and the outpost route has priority 15 above the app route's 10.
