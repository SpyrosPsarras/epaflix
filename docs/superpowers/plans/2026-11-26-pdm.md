# PDM replaces PegaProx Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run Proxmox Datacenter Manager in VM 1022 with the `e-pavli` cluster and the PBS as remotes, reachable at `pdm.epaflix.com` with Authentik login, then retire PegaProx (CT 1021).

**Architecture:** A VM installed unattended from the PDM ISO. Traefik routes `pdm.epaflix.com` to it with Authentik forward-auth, as for PegaProx today. PDM has an OpenID realm against a new Authentik provider defined in the existing Authentik IaC blueprint.

**Tech Stack:** Proxmox Datacenter Manager ISO and `proxmox-auto-install-assistant`, Pi-hole dnsmasq, Traefik IngressRoute, Authentik blueprint (SOPS), `vault run`.

**Spec:** `docs/superpowers/specs/2026-11-26-pdm-design.md`

## Global Constraints

- VM 1022 `pdm` on evanthoulaki, `local-raid`, 2 cores, 4 GiB, 40 GB, `onboot: 1`, `agent: 1`, `vmbr0`, `192.168.10.22/24`, gateway `192.168.10.1`, DNS `192.168.10.30`.
- Repository `pdm-no-subscription`; enterprise source disabled.
- Hostname `pdm.epaflix.com`; backend port 8443.
- No secret in chat, logs or git. Secrets go through `vault run` or SOPS (S1, S5).
- Every live change (VM, Authentik, tokens, DNS on Pi-hole, `Endpoints`, CT 1021) needs Spyros's yes first (S8).
- PR 1 holds Tasks 1 to 5. PR 2 holds Task 6, after Spyros confirms PDM works and a few days pass.

## Review Focus

- Authentik is down: PDM must still be reachable at `https://192.168.10.22:8443` with `root@pam`. Task 3 checks this.
- evanthoulaki is down: PDM is down with it, and nothing else may depend on PDM. Task 4 checks that no job, alert or script calls PDM.
- A PVE or PBS certificate changes (9.3 renews the cluster CA): the remote shows a fingerprint error. Task 4 records where to update it in the README.
- The PDM self-signed certificate: Traefik must reach it with a `ServersTransport` that sets `serverName: pdm.epaflix.com`. Task 2 checks the route answers through Traefik.
- Stale PegaProx references after removal. Task 6 greps for `pegaprox` and `192.168.10.21`.
